# Tutorial de Nova 3.0.0

## 1. Navegación Air/Safari
Abre `nova://safari` para activar o desactivar Safari Air. La barra se vuelve más compacta y las pestañas reciben una apariencia suave.

## 2. Pestañas
El botón `+` permanece junto a la última pestaña. `Ctrl/Cmd + clic` o clic central sobre un enlace lo abren en otra pestaña. `Ctrl/Cmd + T` crea una pestaña nueva.

## 3. Islands y Spaces
`nova://islands` permite crear y gestionar grupos de pestañas relacionados. `nova://workspaces` guarda un contexto completo para restaurarlo más tarde.

## 4. Glance
Usa Alt + clic sobre un enlace para abrir la previsualización sin convertirlo inmediatamente en una pestaña permanente.

## 5. Command Center
Pulsa `Ctrl/Cmd + K`. Busca acciones como “Safari Air”, “Writer”, “Focus”, “Reading List” o una pestaña abierta. También puedes usarlo para acceder a herramientas del sistema.

## 6. Focus
Abre `nova://focus`. Elige 25, 50 o minutos personalizados. La interfaz se reduce durante la sesión y puedes salir con el botón del indicador inferior.

## 7. Reader+
Abre `nova://reader`. “Extraer y abrir Reader” copia el contenido principal a una vista limpia; “Aplicar estilo” transforma la página actual sin abrir otra pestaña.

## 8. Reading List
Abre `nova://reading`. Guarda la página actual y marca elementos como leídos cuando termines.

## 9. Writer y Docs
`nova://writer` abre el editor. El documento se guarda localmente de forma automática. `DOCX` genera un Word real; `HTML` guarda una copia HTML en Descargas. `nova://docs` muestra todos los documentos.

## 10. Study
`nova://study3` reúne Reader+, Collections, Reading List y Writer en un flujo de investigación.

## 11. Collections y Nova Send
`nova://collections` permite crear colecciones y guardar la página actual. `nova://send` sirve para enviar la página a Collection, Reading List, Study o Writer.

## 12. Privacy / Performance / Downloads
Usa `nova://privacidad2`, `nova://rendimiento2` y `nova://descargas2` para revisar protecciones, memoria y descargas.

## 13. Nova Apps y Web Panels
En `nova://apps` añade una URL y un nombre; “Abrir app” la lanza en una ventana propia de Nova. En `nova://panels` añade webs de consulta para tenerlas como paneles dentro del espacio.

## 14. Media Hub
`nova://media` muestra pestañas con audio activo y permite silenciar o controlar reproducción.

## 15. Gestor de pestañas y sesiones
`nova://pestanas` sirve para localizar pestañas y posponerlas. `nova://sesiones` guarda y restaura conjuntos de pestañas.

## 16. QR
`nova://qr` genera un QR de la página actual para abrirla rápidamente desde otro dispositivo.

## 17. Backup
`nova://backup` exporta la configuración sin incluir la clave API. También permite importar un JSON de backup.

## 18. Mejoras
`nova://mejoras` es el lugar para proponer cambios. Los votos de la versión local son por dispositivo; el enlace a GitHub sirve para una propuesta global.
