# Nova 5.3.4 — Chrome Polish & Button Fixes

## Correcciones
- Conectados los controles de ventana Minimizar, Maximizar y Cerrar.
- Revisados los controles de navegación y menú para evitar acciones muertas.
- Añadidos manejadores con fallback para acciones externas.
- Ajustada la creación de la interfaz para mantener la navegación web separada del shell de Nova.

## Interfaz
- Nueva barra superior inspirada en la simplicidad de los navegadores Chromium.
- Pestañas más compactas y con mejor jerarquía visual.
- Botones con superficies grises suaves para distinguir los controles.
- Menús, tarjetas y ajustes con un sistema de espaciado y bordes coherente.
- Mejoras en modo claro y oscuro.

## Compatibilidad
- Se mantienen navegación, favoritos, historial, descargas, Workspaces y extensiones Chromium.
- No se introducen nuevos sistemas de temas ni funciones experimentales en la barra principal.
