# Nova 5.1.0 Quantum Hotfix

## Enfoque
Nova 5.1.0 prioriza estabilidad, recuperación y una interfaz sin opciones huérfanas. Esta versión consolida Quantum y elimina del flujo de usuario los temas, logotipos y menús heredados que ya no forman parte del producto.

## Añadido
- Centro de diagnóstico Quantum.
- Copias de seguridad y restauración de estado.
- Reparación de interfaz sin borrar favoritos, historial ni Workspaces.
- Centro de actualizaciones.
- Paleta rápida `Ctrl+K` para pestañas, favoritos, historial y acciones.
- Modo lectura accesible desde Ajustes/Acciones.
- Página de novedades recontextualizada para el ciclo actual.

## Cambiado
- Ajustes reducidos a opciones realmente existentes.
- Un único logotipo oficial Quantum.
- Apariencia limitada a Sistema, Claro y Oscuro.
- Menús heredados ocultos del flujo principal.
- La configuración visual antigua se normaliza al arrancar para evitar estados incompatibles.

## Corregido
- Rutas antiguas de temas y logotipos que podían seguir apareciendo después de una actualización.
- Persistencia de preferencias visuales heredadas que podía dejar la interfaz en un estado incoherente.
- Riesgo de perder el estado útil cuando una preferencia inválida se serializa.

## Compatibilidad
- Se conservan favoritos, historial, descargas, perfiles, Workspaces y extensiones existentes.
- La actualización no pretende cambiar todavía el modelo de seguridad del renderer: esa migración queda aislada para una futura actualización técnica.

## Limitaciones conocidas
- El renderer principal conserva Node integration por compatibilidad con el núcleo histórico.
- No se incluye `package-lock.json` porque no se ha generado a partir de una resolución reproducible en este entorno.
- El `.exe` final debe validarse en Windows/GitHub Actions.
