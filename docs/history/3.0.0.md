# Nova 3.0.0 — Legacy Foundation

## Estado actual
Esta versión es histórica. Sus decisiones de producto se consideran parte de la evolución de Nova, pero **no** representan la interfaz ni las opciones disponibles en Nova 5 Quantum.

## Aporte al proyecto
- Consolidó páginas internas y herramientas de navegador en una base modular.
- Preparó capacidades que más tarde se organizaron en Workspaces, rendimiento, privacidad y productividad.
- Sirvió como punto de partida para las capas 4.x y Quantum.

## Relectura para 5.1
Nova ya no expone los antiguos selectores visuales ni las configuraciones específicas de aquella etapa. Las funciones activas actuales están documentadas en `RELEASE_NOTES_5.1.0.md`.
