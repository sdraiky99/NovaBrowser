# Nova 3.1.0 — Legacy Foundation

## Estado actual
Esta versión es histórica. Se conserva para documentar la evolución de Nova, no como catálogo de funciones activas.

## Aporte al proyecto
- Refinó la arquitectura de herramientas heredada de Nova 3.0.
- Ayudó a consolidar navegación, páginas internas y flujos de productividad.
- Sus ideas sirvieron de puente hacia la organización que terminaría en Quantum.

## Relectura para 5.1
Los sistemas visuales, logotipos y menús de esa generación han sido retirados del producto visible. Nova 5.1 mantiene solo las funciones que siguen teniendo implementación y pruebas actuales.
