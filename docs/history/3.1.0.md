# Nova 3.1.0 — Historia del proyecto

Esta nota conserva el contexto de Nova 3.1.0. Esa rama es **legacy** y no representa la UI ni las funciones activas del producto actual.

## Qué aportó
- Refinó navegación, herramientas y organización sobre la base 3.0.
- Preparó la transición hacia las ramas 4.x y el sistema Quantum.

## Estado actual
Nova 3.1.0 fue sustituida por generaciones posteriores. Esta página existe para conservar la historia del proyecto sin mezclar funciones antiguas con la interfaz actual.
