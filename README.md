# Nova 4.4.1

Nova es un navegador Chromium para escritorio con una interfaz Glass Clean, Workspaces, herramientas de rendimiento, extensiones y una nueva pestaña con noticias en vivo.

## Desarrollo

- `npm install`
- `npm run start`
- `npm run check`
- `npm run dist:win`

## Noticias

La nueva pestaña consulta RSS públicos de fuentes identificables y enlaza siempre al artículo original. Si no existe conexión, muestra contenido interno bajo la etiqueta **Nova Briefing**.
