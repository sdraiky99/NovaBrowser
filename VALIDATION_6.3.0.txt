ALCANCE DEL MICROBENCHMARK
--------------------------
El test solo mide una función JavaScript pura que decide cómo resolver una URL o una consulta de búsqueda. No mide el arranque completo de Electron, la carga de páginas, el uso de CPU/RAM de contenidos web ni la velocidad de la conexión. La cifra es específica de esta ejecución y equipo.

LIMITACIONES CONOCIDAS
----------------------
- Este paquete contiene el proyecto fuente; no se afirma que los ejecutables EXE se hayan compilado en este entorno.
- No se garantiza compatibilidad universal con Chrome Web Store ni con todas las APIs de extensiones.
- El renderer local principal conserva nodeIntegration: true y contextIsolation: false por dependencias heredadas; una migración segura requiere una refactorización y pruebas de regresión específicas.
- No se incluye package-lock.json; para reproducibilidad estricta debe generarse y revisarse en un entorno con acceso a npm.
- Las pruebas estáticas y lógicas no sustituyen la ejecución interactiva del navegador en Windows.
