# Nova 2.5.0

Nova 2.5.0 reorganiza la experiencia alrededor de una superficie limpia y funciones profundas bajo demanda.

## Lo principal
- Safari Mode con navegación compacta y aspecto cristalino.
- Nova Islands para organizar pestañas por proyecto/contexto.
- Glance para previsualizar enlaces antes de abrirlos.
- Command Center ampliado con acciones y páginas internas.
- Focus y Reader+ para concentración y lectura.
- Colecciones, Web Capture y Web Apps.
- Nova Writer y Nova Docs, con exportación `.docx` real.
- Nova Study 3 como flujo de lectura, investigación y escritura.
- Centro de privacidad y Centro de rendimiento reunidos.
- Download Hub.
- Setup/primer arranque rehechos con menos pasos.
- `nova://mejoras` para proponer y votar mejoras localmente o abrir GitHub Issues.
- Novedades con imágenes locales dentro de `assets/release/2.5/`.

## Atajos nuevos
- Alt + clic: Glance.
- Ctrl/Cmd + K: Command Center.
- Ctrl + Shift + N: crear una Island desde la pestaña actual.

## Documentos
Nova Writer genera un paquete DOCX válido y lo guarda en Descargas. El contenido se guarda primero en el perfil local de Nova.

## Privacidad
Las propuestas guardadas en `nova://mejoras` permanecen en el perfil local. La opción de GitHub abre la página pública de Issues del repositorio.
