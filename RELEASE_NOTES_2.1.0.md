# Nova 2.1.0 — Nova Tab Hub

Nova 2.1.0 mantiene las funciones existentes y añade una capa organizada desde Nova Tab.

## Nuevo
- Centro Nova 2.1 desde la nueva pestaña.
- Study 2.1 con accesos de Tutor, Examen, contexto y enfoque.
- Gestor de pestañas.
- Memoria local opcional.
- Nova Turbo y modo enfoque.
- Centro PDF y Media Hub.
- Accesos centralizados para Workspaces, Notas, Seguridad, Perfiles, Sync y Extensiones.
- Acciones rápidas desde el nuevo centro.

## Conservado
- Bloqueador de anuncios.
- Extensiones existentes.
- Barra de marcadores inferior y menú contextual.
- Migración Chrome / Edge / Firefox.
- Cuenta Nova y sincronización.
- Study, Workspaces, seguridad, rendimiento y accesibilidad de 2.0.

## Seguridad
Las funciones nuevas no cambian automáticamente datos del navegador de origen ni envían el contenido de una página a un proveedor de IA sin una acción explícita del usuario.
