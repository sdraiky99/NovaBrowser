# Seguridad en Nova

Gracias por ayudar a mejorar Nova. Si encuentras una vulnerabilidad de seguridad, evita publicar detalles explotables en un issue público.

Envía una descripción privada al propietario del repositorio o utiliza la función de **Security advisories** de GitHub si está habilitada.

Incluye, cuando sea posible, la versión de Nova, sistema operativo, pasos para reproducir el problema y el impacto observado. No incluyas contraseñas, tokens, claves API ni datos personales.

Nova no debe necesitar privilegios de administrador para funcionar normalmente.
