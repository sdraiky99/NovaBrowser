NOVA 2.4.5 · INSTALACIÓN Y PUBLICACIÓN
======================================

WINDOWS
-------
1. Sube el contenido del ZIP al repositorio conservando .github/.
2. El workflow `.github/workflows/build.yml` comprueba y compila Windows y Linux en cada push/PR.
3. Para publicar una versión crea un tag, por ejemplo:

   v2.4.5

   El workflow `.github/workflows/release.yml` publica los EXE, RPM, AppImage y SHA256SUMS.txt.
4. El Setup de Nova usa NSIS y está configurado para actualizar sobre una instalación existente; el updater de Electron descarga la nueva versión cuando el build es una instalación compatible.
5. El Portable no se registra como navegador predeterminado.

FEDORA / LINUX
--------------
- RPM: `sudo dnf install ./Nova-2.4.5-x86_64.rpm`
- AppImage: `chmod +x Nova-2.4.5-x86_64.AppImage && ./Nova-2.4.5-x86_64.AppImage`
- También puedes usar `fedora/install-fedora.sh` para buscar e instalar el RPM publicado más reciente.

IMPORTACIÓN
-----------
La migración detecta perfiles locales de Chrome, Edge y Firefox e importa marcadores e historial en modo solo lectura. Las contraseñas cifradas del navegador de origen no se extraen.

CUENTAS NOVA
------------
La cuenta usa el formato `usuario@Nova.com`. El backend de referencia de `account-server/` debe exponerse detrás de HTTPS si se despliega para uso real.

SEGURIDAD
---------
Hay validación de IPC, sandbox y aislamiento de webviews, control de navegación, permisos y copias atómicas. Consulta `SECURITY-AUDIT-2.2.0.md` para los hallazgos pendientes, especialmente la migración futura a preload/contextBridge y la ausencia de lockfile.
