# Nova 3.1.0 — New Things

Nova 3.1.0 añade una capa nueva de funciones sin reemplazar los sistemas existentes de Nova 3.0.1.

## Nuevas funciones
- Quick Actions
- Pinboard
- Nova Memory
- Smart Tab Groups
- Search Anything
- Link Preview
- Website Themes por sitio
- Smart Notifications
- Permission Center
- Nova Automations
- Mini Mode
- Nova Send local
- Page Snapshot HTML
- Nova Daily
- One-Click Cleanup

## Acceso
El botón **✨ Nuevas** abre el nuevo centro. También aparece en el Command Center y en el Centro Nova anterior.

## Compatibilidad
Las funciones principales de Nova 3.0.1 se mantienen como estaban; Nova 3.1.0 añade una capa independiente en `shell/nova31.js`.
