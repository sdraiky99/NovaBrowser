# Nova 4.0.0 — Ultimate Workspace

Nova 4.0.0 añade una capa nueva encima de la arquitectura 3.x. Las funciones existentes se conservan y se conectan desde un hub único.

## Nuevas áreas
- Nova Ultimate Hub + Nova Launcher
- Nova Dock y accesos rápidos
- Page Brain y Talk to Page
- Research Mode
- Nova Vault, Timeline y Continue Anywhere
- Web Superpowers por sitio
- Visual Search y Magic Translate
- Workspaces+, Islands 2.0 y Spaces 2.0
- Nova Studio
- Nova Flows
- Extensions 2.0
- Nova Companion y Nova Sync
- Desktop Mode
- Puente de descubrimiento hacia las herramientas Nova 3.x existentes

## Conservación
Los módulos legacy de Nova 3.0/3.1 no se sustituyen. nova40.js es una capa aditiva.
