# Changelog — Nova 4.4.0

## 4.4.0 — Professional

- Sidebar profesional con Workspaces y Rendimiento.
- Workspaces rápidos y guardado de pestañas actuales.
- Centro de rendimiento con métricas por pestaña.
- Ahorro de energía manual y automático por batería.
- Carga de extensiones Chromium reales desde carpeta (`manifest.json`).
- Integración de extensiones por perfil y gestión de retirada.
- Animaciones Glass Clean refinadas y respetuosas con reducción de movimiento.
- QA y comprobaciones de proyecto actualizadas a 4.4.0.

No se reescribe la shell principal: las funciones nuevas se añaden de forma incremental sobre la base estable de 4.3.2.
