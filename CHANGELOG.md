# NOVA X — Changelog

## 10.0.0 — NOVA X First Generation Rebuild
- Rebuilt the modern browser chrome with a radical visual system while preserving the NOVA mark.
- Kept horizontal and vertical tab layouts switchable within the same session.
- Moved NOVA Shield to the upper toolbar and added session/per-site counters based on Ghostery blocked-request events.
- Added request type, destination hostname and cautious best-effort rule classification to the Shield panel.
- Replaced the first-run walkthrough with a five-step, skippable welcome tour.
- Updated Electron to 45.4.1 (Chromium 156.0.8078.100), Ghostery blocker to 2.20.3, and electron-builder to 26.18.1.
- Preserved separate per-user Setup and Portable distributions.
