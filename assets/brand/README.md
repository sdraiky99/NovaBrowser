# Nova — identidad Minimal Reborn

- `nova-mark.svg`: fuente vectorial editable de la N geométrica minimalista, sin fondo.
- `nova-icon.png`: imagen RGBA transparente derivada del SVG para Electron/HiDPI.
- `nova.ico`: icono Windows multi-resolución derivado del mismo SVG.

Los tres recursos corresponden a la misma marca para evitar diferencias entre la interfaz, la ventana y el instalador.
