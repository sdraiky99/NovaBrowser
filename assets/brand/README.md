# Nova Deluxe — identidad de marca

- `nova-mark.svg`: fuente vectorial original, sin fondo, para UI y favicon.
- `nova-icon.png`: variante RGBA de 512 × 512 para Electron y pantallas HiDPI.
- `nova.ico`: icono multi-resolución de Windows para ventana, instalador y barra de tareas.

La marca es una N geométrica con profundidad azul/cian/violeta. No contiene una placa ni un fondo opaco; el fondo transparente permite usarla en superficies claras y oscuras.
