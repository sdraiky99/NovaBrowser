# Nova 1.6.4

Actualización grande y aditiva. No se eliminan funciones de versiones anteriores.

## Marcadores
- Barra inferior opcional, persistente y ocultable.
- Clic derecho en marcadores y carpetas.
- Importación/exportación JSON y HTML.

## Migración
- Detección de Chrome, Edge y Firefox.
- Marcadores e historial compatibles en modo solo lectura.
- No se extraen contraseñas cifradas ni se modifican perfiles de origen.

## Bienvenida y novedades
- Bienvenida visual con imágenes locales.
- Accesos directos a Novedades, marcadores, migración y rendimiento.
- Entrada de Novedades completa para 1.6.4.

## Rendimiento y RAM
- Lectura de RAM y CPU de Nova.
- RAM total/libre del sistema.
- Memoria y CPU por pestaña web.
- Limpieza de caché y modo opcional de ahorro de memoria.

## Seguridad y estabilidad
- Webviews con sandbox, aislamiento de contexto y Node desactivado.
- Popups y navegación no autorizada controlados.
- Permisos de sitios gestionados desde el proceso principal.
- Recuperación de renderers bloqueados.
- Validación de IPC y copias atómicas del estado.

## Extensiones nuevas
- Aviso de conexiones HTTP.
- Marcado de enlaces no HTTPS.
- Limpieza de parámetros de seguimiento.
- Vídeo ligero.

## Compatibilidad
La compilación de Windows sigue preparada mediante GitHub Actions para generar `Nova-Setup-1.6.4.exe` y `Nova-Portable-1.6.4.exe`.
