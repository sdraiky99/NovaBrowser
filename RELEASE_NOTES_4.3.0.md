# Nova 4.3.0 — Glass Clean

## Interfaz
- Nueva identidad Glass Clean: transparencia ligera, blur moderado y bordes suaves.
- Tipografía prioritaria: Inter, con Segoe UI Variable/Segoe UI como respaldo.
- Animaciones cortas para pestañas, menús, botones y paneles; respeta reducción de movimiento.
- Iconos SVG unificados para el chrome del navegador; se eliminan emojis de la navegación principal.

## Sidebar y fijados
- Sidebar simplificada: Inicio, Favoritos, Historial, Descargas, Workspaces, Extensiones, Ahorro de energía y Ajustes.
- Nuevo botón para fijar la web actual en la barra lateral.
- Los fijados conservan el favicon real del sitio con fallback seguro.
- Menú contextual del fijado permite quitarlo.

## Rendimiento
- Nuevo Ahorro de energía para reducir trabajo en pestañas en segundo plano.
- Las animaciones de contenido se limitan cuando las pestañas están inactivas en Eco.

## Extensiones
- Página de extensiones con accesos oficiales a uBlock Origin Lite, Bitwarden y Dark Reader.
- Soporte para cargar extensiones WebExtension desempaquetadas desde una carpeta local.

## Mantenimiento
- Auditoría de controles de UI para detectar botones nucleares sin acción.
- Se mantiene compatibilidad con preferencias existentes y no se elimina el directorio de datos de usuario al desinstalar.

> Las URLs y referencias de las extensiones oficiales se verificaron el 6 de octubre de 2026.
