# Nova 4.1.0 · Evolution Update

Actualización incremental de Nova 4.0.0. No sustituye los módulos existentes.

## Nuevas funciones
- Nueva página de pestaña: búsqueda central, noticias personalizadas y fondo dinámico.
- Centro de privacidad 4.1 con bloqueador de anuncios y protección inteligente.
- Nova Sync 4.1 con favoritos, pestañas, historial, configuración y perfil preparados para sincronización cifrada.
- Extensions Store con destacadas, permisos visibles y compatibilidad como objetivo.
- Game Hub: Mis juegos, noticias gaming y estadísticas.
- Perfil Gaming independiente con apariencia, configuración, extensiones, privacidad y sincronización.
- Magic Translate 4.1 y acceso directo a herramientas de desarrollador.

## Compatibilidad
La aplicación de escritorio mantiene la base Electron/Chromium existente. Esta actualización añade la experiencia y el modelo de sincronización pensados para Windows + Android; no fabrica un APK Android dentro de este paquete Electron.
