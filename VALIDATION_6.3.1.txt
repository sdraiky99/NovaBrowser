LÍMITES DE ESTA VALIDACIÓN
--------------------------
- El microbenchmark solo mide una función JavaScript pura para resolver URL o consulta; no mide tiempo de arranque, carga de páginas, CPU/RAM total ni rendimiento comparado de la versión anterior.
- No se ejecutó una conversación de IA real: no se presupone que Ollama, un modelo local o un servicio online estén disponibles en este entorno.
- No se instalaron las dependencias de la aplicación en este entorno ni se abrió una ventana Electron interactiva.
- No se generaron ni probaron EXE de Windows aquí. Los workflows de GitHub Actions están configurados para compilar y comprobar Setup y Portable en un runner Windows.
- Este paquete no incluye `package-lock.json`; las dependencias transitivas se resolverán al ejecutar `npm install`.

LIMITACIONES CONOCIDAS
----------------------
- Nova Assist local requiere Ollama y un modelo instalado por separado. El proveedor online transmite las consultas a un servicio externo.
- La lectura del texto de la página está limitada al momento en el que el usuario activa la casilla de contexto; el usuario puede también insertar texto seleccionado explícitamente.
- El renderer principal conserva `nodeIntegration: true` y `contextIsolation: false` por la arquitectura heredada. La integración de IA no corrige ese problema de arquitectura, y no se afirma que Nova sea completamente segura.
- La compatibilidad con extensiones Chromium/Web Store continúa limitada por la implementación de Electron.
