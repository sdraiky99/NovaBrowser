# Contribuir a Nova

Mantén los cambios pequeños y centrados. No introduzcas telemetría, publicidad, cambios de comportamiento no relacionados o acceso innecesario a datos del usuario.

Antes de abrir un pull request, ejecuta `npm run check` y comprueba el flujo que hayas modificado.

Las nuevas funciones que lean datos locales deben usar rutas conocidas, validar entradas y trabajar en modo lectura cuando no sea necesario escribir.
